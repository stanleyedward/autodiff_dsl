# Benchmarks

Generated by `python apps/splat2d/bench.py`. 256x256 image, one GPU thread per pixel. Stack = slots the compiler allocates per thread for the reverse pass (4 bytes each); total = per thread x W*H. FPS = `rev_render` dispatches per second: the median over 5 batches of 50 runs (range in parentheses), with the configs in each table timed in alternation.
